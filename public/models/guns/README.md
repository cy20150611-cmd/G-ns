# Gun models

Drop `.glb` files here, named after the gun they replace:

`rifle.glb`, `smg.glb`, `shotgun.glb`, `sniper.glb`, `lmg.glb`, `dmr.glb`, `pistol.glb`, `revolver.glb`, `knife.glb`

The game resizes each model to a realistic length and points its longest side forward,
so any size works. Models that point the barrel along -Z with the grip near the center look best.
